
# FitTrack — Gerenciador de Treinos


**Disciplina:** Desenvolvimento de Interfaces Web (PUC Minas)**Etapa:** 1 — HTML e Estrutura da Interface Semântica

##  Sobre o Projeto

O **FitTrack** é uma aplicação web desenvolvida para auxiliar usuários a planejarem, cadastrarem e acompanharem suas rotinas de exercícios físicos diários e semanais.

##  Tecnologias e Padrões Utilizados

* **HTML5 Semântico:** Estruturação da interface utilizando tags semânticas (`header`, `nav`, `main`, `section`, `article`, `footer`, `fieldset`), mantendo o código limpo e sem o uso de elementos de estilização vazios (`<div>`).
* **CSS3:** Organizado na pasta `assets/css/` para estilização e responsividade da interface.
* **Funcionalidades da Etapa 1:**
  * Formulário completo para cadastro de nova ficha de treino.
  * Seção de listagem dos treinos cadastrados com campos de busca e filtros.
  * Área detalhada para exibição dos exercícios de cada ficha.

##  Como Executar

Basta clonar este repositório e abrir o arquivo `index.html` diretamente em qualquer navegador web moderno.
